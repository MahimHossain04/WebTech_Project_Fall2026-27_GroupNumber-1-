# PabeKothay 🎓

**A University Student Marketplace for Buying & Exchanging Items**

PabeKothay is a web-based marketplace where university students can buy, exchange, and post items such as books, lab kits, calculators, and stationery.

### Features
- **Student Panel:** Browse items, search/filter, manage posts, cart, and requests.
- **Buy & Exchange:** Submit and track buying or exchange requests.
- **Admin Panel:** Manage students, moderate listings, and approve/reject requests.
- **Request Tracking:** Monitor Pending, Approved, Rejected, and Completed statuses.
- **Account Management:** Update profiles and passwords.

### Tech Stack
HTML, CSS, JavaScript, Backend (PHP), Database (MySQL or SQL Server).

### Project Scope
A student marketplace for buying and exchanging items. 

**Tagline:** *Find what you need, Share what you have.*
